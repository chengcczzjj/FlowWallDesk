# 灵月 — 项目开发指南

## 项目简介

Windows 桌面 AI 伴侣应用。功能：动态壁纸、桌面组件、桌宠（后期）。

## 技术栈

Electron + React + TypeScript + Vite + Tailwind CSS + Shadcn/UI + Zustand + electron-store + electron-builder

## 关键依赖

- `electron-as-wallpaper` — 壁纸窗口嵌入桌面
- `electron-store` — 本地持久化

## 窗口架构

| 窗口 | 说明 |
|------|------|
| 主界面 | 灵月的核心操作界面，控制壁纸/组件/桌宠的一切配置 |
| 壁纸窗口 | 全屏 + `attach()` 嵌入桌面图标层下方，播放视频或特效 |
| 组件画布 | 单个全屏透明窗口，所有桌面组件在此窗口内渲染（不要每个组件开独立窗口，避免内存爆炸） |
| 系统托盘 | 右键菜单：打开主界面、退出 |

组件画布的鼠标穿透：鼠标在组件上 → `setIgnoreMouseEvents(false)`；在空白区域 → `setIgnoreMouseEvents(true, { forward: true })`。

主进程与渲染进程通过 `contextBridge` + `preload.ts` 通信。

## 文件结构

```
src/
├── main/            # 主进程（窗口管理、托盘、IPC）
├── preload/         # contextBridge 暴露 API
├── renderer/
│   ├── main-ui/     # 主界面
│   ├── canvas/      # 组件画布（拖拽容器）
│   └── widgets/     # 各桌面组件（Clock、TodoList、Focus、Dock…）
└── shared/          # 共享类型
```

## 开发顺序

### 第一步：实现完整的壁纸功能

目标：用户在主界面选一个视频 → 桌面壁纸立刻切换成该视频。

1. 用 `guasam/electron-react-app` 模板初始化项目骨架（Electron + React + TS + Vite + Tailwind）
2. 配置 `preload.ts` 和 IPC 通信基础结构
3. 克隆 [meslzy/electron-as-wallpaper](https://github.com/meslzy/electron-as-wallpaper) 研究其 examples 目录中的用法，然后在项目中 `npm install electron-as-wallpaper` 安装
4. 创建壁纸窗口：全屏无边框 BrowserWindow，内部用 `<video>` 播放视频，调用 `attach()` 嵌入桌面
5. 创建系统托盘：托盘图标 + 右键菜单（打开主界面、退出应用）
6. 按用户设计稿开发主界面的壁纸管理模块：浏览本地视频文件、预览、选择应用
7. 打通主界面 → 主进程 → 壁纸窗口的联动：用户在主界面点击"应用" → IPC 通知主进程 → 壁纸窗口切换视频源
8. 壁纸参数持久化：用 electron-store 保存当前壁纸路径和参数，下次启动自动恢复

### 第二步：实现桌面组件功能

目标：用户在主界面添加一个组件（如时钟） → 桌面上出现该组件，可拖动、可交互。

1. 创建组件画布窗口：全屏透明无边框 BrowserWindow，实现鼠标穿透逻辑（`setIgnoreMouseEvents` 动态切换）
2. 开发第一个桌面组件（时钟），在画布窗口中用 React 绝对定位渲染，实现拖拽
3. 按用户设计稿开发主界面的组件管理模块：组件列表、添加/移除按钮
4. 打通主界面 → 主进程 → 组件画布的联动：用户在主界面点击"添加时钟" → IPC → 画布窗口渲染时钟组件
5. 组件状态持久化：位置、大小、开关状态存入 electron-store，启动时恢复
6. 开发更多组件：TodoList、专注计时、Dock 栏等

UI 设计稿由用户提供，按稿还原。

# 桌面图标收纳组件实现方案

## 功能概述

用户从桌面框选图标拖入组件窗口，组件解析并展示这些快捷方式，桌面上的原始文件随即删除。点击组件内图标可启动对应程序。支持从组件拖回桌面或右键移回。

## 核心流程

```
桌面图标拖入组件 → drop 事件获取文件路径列表 → 解析 .lnk（名称、目标路径、图标）
→ 存入 electron-store → 组件内渲染 → fs.unlink 删除桌面原始文件
```

反向操作：组件内右键"移回桌面"或拖出 → 复制 .lnk 回桌面目录 → 从 store 中删除。

## 关键细节

- 桌面目录有两个：`C:\Users\{用户}\Desktop` 和 `C:\Users\Public\Desktop`，删除时注意路径匹配
- 图标提取用 Electron 自带的 `app.getFileIcon(filePath)`，返回 NativeImage 可直接转 base64 显示
- 透明窗口的完全透明像素区域不接收 drop 事件，组件底板必须有可见背景（毛玻璃底板本身满足）
- 点击启动用 `shell.openPath(targetPath)`
- 拖入的不一定都是 `.lnk`，也可能是 `.exe`、`.url`、文件夹等，都需要处理
- 删除桌面文件前建议先确认存储成功，避免数据丢失
- 解析 `.lnk` 文件可用 `shell-link` 或 `windows-shortcuts` 这类 npm 包，提取目标路径和参数

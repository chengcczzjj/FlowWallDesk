# 组件毛玻璃效果实现方案

## 为什么不能用系统级方案

Electron 的 `backgroundMaterial: 'acrylic'` 无法采样到通过 `electron-as-wallpaper` 嵌入的视频壁纸内容，DWM 只能采样到系统原始壁纸。CSS 的 `backdrop-filter: blur()` 只能模糊同一窗口内的 DOM，不能跨 BrowserWindow。

## 方案：壁纸抽帧广播 + CSS 模糊

壁纸窗口是唯一的视频源。用隐藏 canvas 定时抽帧，缩小到 192×108，以 JPEG base64 格式通过 IPC 广播给所有组件窗口。组件窗口用 `<img>` 显示这张小图，根据自身屏幕坐标做偏移对齐，CSS `filter: blur(20px)` 模糊，上层叠半透明色调遮罩和实际 UI。

```
壁纸窗口 → canvas 抽帧(192×108, ~12fps, JPEG 0.5) → IPC → 主进程 → 广播给所有组件窗口
组件窗口 DOM 结构：<img>(偏移对齐+blur, pointer-events:none) → 遮罩层(rgba半透明) → 组件UI(z-index:1)
```

## 关键细节

- 抽帧帧率 10~15fps 即可，模糊内容帧率低不明显
- img 拉伸到屏幕尺寸，用 left/top 负值偏移到组件对应的屏幕位置，裁切显示
- 组件拖动时监听 move 事件，实时更新偏移量保持对齐
- img 层设 `pointer-events: none`，不影响上层 UI 交互
- 稍微 `scale(1.1)` 防止模糊边缘露白
- 建议封装为通用的 `FrostedGlassBackground` 组件，所有 widget 复用

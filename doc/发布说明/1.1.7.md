# LingyueDesk 1.1.7 发布说明

> 发布日期：2026-08-29  
> 版本主题：启动锁屏后桌面组件输入恢复

## 核心更新

- 修复开机自启动后长时间停留在 Windows 锁屏界面，再进入桌面时便利贴可见但无法点击、输入或拖动的问题。
- 启动期长时间遮挡返回桌面后无损重建透明 Canvas 输入窗口，保留现有壁纸、组件和便利贴数据。
- 增加原生鼠标按下与 renderer 回执监测；检测到真实 `pointerdown` 丢失时自动重建 Canvas，不再依赖用户重启应用。
- 收紧 z-order 自愈边界，仅在 Windows 原生命中仍落到桌面 Shell 时重组合，避免便利贴或 Dock 边缘误触发全屏透明窗口抬升。
- 移除普通桌面组件周围不必要的扩大命中区域，降低透明 Canvas 吞掉相邻桌面点击的概率。

## 验证结果

- `npm.cmd test`：类型检查、lint 和 51 项单元/契约测试全部通过。
- `npm.cmd run build:win`：Windows x64 NSIS 安装包、blockmap 和 `latest.yml` 构建成功。
- 本机安装态：EXE、`app.asar` 和卸载注册表均为 1.1.7；8 个壁纸组件、2 个全局图标组件及当前壁纸配置完整保留，正式安装进程启动正常。

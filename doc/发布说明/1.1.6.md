# LingyueDesk 1.1.6 发布说明

> 发布日期：2026-08-27  
> 版本主题：按显示器独立壁纸分配修复

## 核心更新

- 移除设置页的显示器布局模式，避免与壁纸页面的目标选择器互相覆盖。
- 本地壁纸页面新增显示器选择器；选择壁纸后点击“应用并保存”，只替换当前选中的显示器。
- 每台连接的显示器使用独立原生壁纸窗口，支持不同显示器保存不同壁纸，重启后自动恢复。
- 旧版本的主屏、复制、延展配置自动兼容到新的按显示器分配逻辑。
- 修复壁纸详情栏遮挡显示器选择和壁纸内容的问题；删除壁纸时同步清理显示器分配。

## 验证结果

- `npm.cmd test`：类型检查、lint 和单元/契约测试全部通过。
- `npm.cmd run build:win`：Windows x64 NSIS 安装包、blockmap 和 `latest.yml` 构建成功。

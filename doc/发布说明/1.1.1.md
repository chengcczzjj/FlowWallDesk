# LingyueDesk 1.1.1 发布说明

> 发布日期：2026-08-18  
> 版本主题：桌面交互稳定性与在线壁纸库

## 核心更新

- 新增在线壁纸库：支持远程清单、下载进度、SHA-256 校验、安全解压、原子安装、版本更新和删除。
- 增加所有者发布管理入口，可将独立壁纸资源发布到 GitHub Release，不再需要随应用版本一起分发壁纸包。
- 修复 Dock 打开应用后自定义图标偶发失效的问题，补齐桌面 Shell 表面下的原生点击兜底。
- 缩短 Dock 启动重复点击保护，避免应用窗口就绪探测期间图标长时间看起来无响应。

## 桌面交互稳定性

- 修复 Windows 应用抢焦、全屏切换或返回桌面时 renderer 丢失 `pointerup`，导致 Canvas 鼠标穿透和组件手势长期锁定的问题。
- 新增原生鼠标状态 watchdog 和 `CANVAS_POINTER_RESET` IPC，自动清理卡住的 CanvasPointerGate、Dock 拖动和便签拖动引用。
- Canvas 合成层修复改为有限重试，并避免在有效拖动过程中触发 z-order 重建。
- 便签输入、直接拖动、缩放和全屏返回后的命中恢复统一走同一套交互自愈链路。

## 验证结果

- `npm.cmd test`：类型检查、lint 和 43 项单元/契约测试全部通过。
- `npm.cmd run build:check`：生产 renderer/main/preload 构建通过。
- `npm.cmd run build:win`：Windows x64 NSIS 安装包、blockmap 和 `latest.yml` 构建成功。
- 本地构建使用未签名内部验证模式；对外分发前应使用 `npm.cmd run build:win:signed` 配置 Windows 代码签名。

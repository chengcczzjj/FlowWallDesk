# LingyueDesk 1.1.13 发布说明

> 源码日期：2026-09-25；由 GitHub Actions（windows-latest）构建并发布
> 版本主题：聊天伙伴可靠地控制和编辑桌面组件、自动更新更可靠、桌面组件层不再闪烁

本版本包含 1.1.12 的全部内容（显示器本地组件坐标、逐屏毛玻璃帧、壁纸设置串行保存），并在其上合并以下更新。

## 聊天伙伴控制组件

- 新增 `arrange_widget`：把组件放到显示器的角落或边缘（锚点）、等比缩放、暂时隐藏或恢复、置顶。位置始终落在组件所在显示器的工作区内，并与用户拖动一样对齐网格、避开其他组件；时钟、天气等按内容等比缩放，卡片和图标收纳保持固定规格。
- `add_widget` 支持选择设计好的预设（preset）和摆放位置（anchor）。所有设置先按组件真实支持的选项校验：数值会被限制到合理范围，不存在的键或取值会被拒绝并返回可选值，AI 不能再宣称改了实际没生效的设置。
- 新增 `update_generated_widget`：修改 AI 生成卡片的标题、内容和配色，而不是删掉重建。生成卡片按内容自动估算高度；浅色/深色主题下强调色文字会自动调整到可读对比度。
- 删除 Dock 和图标收纳前需要确认，避免误删常驻入口。组件列表只返回设置摘要，不再把图标数据、便笺 HTML 塞进对话上下文。
- 刚操作过组件后，“再大一点”“换个位置”这类追问会继续使用组件工具。
- 聊天过程提示修正：生成卡片不再显示成“移除桌面组件”，并显示组件名称或数量。
- 内置预设与桌面编辑工具栏的选项一致；音频可视化的“环形”样式补上了实际绘制。

## 自动更新

- 启动检查或下载失败后按 2、10、30、60 分钟退避重试，不再等到下一个 6 小时周期。
- 电脑从睡眠唤醒后，如距上次检查超过 1 小时会重新检查。
- 发现新版本后自动在后台下载；下载完成后弹出系统通知（点击即重启更新），托盘菜单也会出现“重启并更新到 …”。安装仍由用户决定，不会在退出时自动安装。

## 桌面组件层

- 打开其他应用或切换输入法时，组件不再闪烁、鼠标指针不再来回跳变；输入和拖拽不需要多次尝试。
- 被其他窗口遮住的组件不再抢占鼠标；命中判断以组件实际绘制的区域为准（包括倾斜的便利贴）。
- 应用壁纸时不再把组件层短暂顶到所有窗口之上。
- 界面修正：添加壁纸对话框不再被壁纸网格遮挡；拖入文件在 Electron 39 下重新可用；Esc 关闭对话框；显示器设置页按真实比例绘制屏幕排列；壁纸列表读取失败时给出提示；其余层级、焦点可见性和文案问题。

## 验证结果

- `npm test`：类型检查和只读 lint 通过；117 项单元/契约测试中，Linux 开发容器内 116 项通过。未通过的 1 项是桌面图标导入测试，依赖 Windows 路径分隔符，在未修改的 1.1.12 源码上同样只在 Linux 失败；发布流程会在 Windows 上重新运行全部测试，失败即停止发布。
- `npm run test:electron:smoke`：协议沙箱、生产壁纸渲染器、显示工具栏三组隔离 Electron 冒烟在 Xvfb 下通过。
- `npm run build:check`：生产构建成功。
- 发布流程在 Windows 上依次执行 `npm test`、Electron 冒烟和 `npm run build:win -- --publish never`；随后核对安装包、blockmap、latest.yml 以及安装包内的版本和入口文件，先上传到草稿 Release，确认资产大小一致后才正式发布，最后从公开地址复核更新清单。以下构建校验由流程自动附加。

## 安装与更新

- 已安装 1.1.12 或更早版本：保持应用运行，自动更新会在后台下载 1.1.13，完成后点击通知或托盘菜单“重启并更新”。也可以在侧边栏更新按钮中手动检查。
- 手动安装：下载本 Release 中的 `lingyue-desk-1.1.13-setup.exe` 覆盖安装，用户数据保留在 userData，不受影响。

## 验收边界

本版本未在 Windows 实机上安装验收。原生窗口层级（开应用、输入法、全屏/锁屏、远程控制）、混合 DPI 多显示器、四种显示模式与热插拔仍需在目标设备上复测。安装包未使用 Windows 代码签名证书。

# LingyueDesk 1.1.11 发布说明

> 构建日期：2026-09-04  
> 版本主题：多显示器稳定布局版

## 核心更新

- 修复壁纸窗口贴入 WorkerW 后仍混用 Electron 绝对坐标、父窗口本地坐标与物理像素的问题；贴合后按 Win32 父级坐标定位并校验最终物理边界。
- 使用 Win32 显示器设备名作为壁纸分配和组件归属的稳定键，不再依赖重启、热插拔后可能变化的 Electron display id。
- 四种显示模式全部改为每显示器一个本地壁纸窗口；跨屏延展由各屏裁切同一虚拟桌面构图，避免一个 BrowserWindow 跨越不同 DPI。
- 组件保存为“显示器稳定键 + 本屏本地坐标”，切换主屏、复制、按屏和延展模式不再改写位置；跨屏拖动会稳定更新归属。
- 毛玻璃帧改为逐屏抽取和选择，副屏组件不再错误采样主屏壁纸；web 壁纸或 renderer 断帧时逐屏捕获兜底。
- 旧版不兼容的多屏布局首次启动安全恢复为仅主显示器；贴合失败自动重试，并记录可核对 expected/actual 边界的显示诊断日志。

## 验证结果

- `npm.cmd test`：类型检查、lint 和 62 项单元/契约测试全部通过。
- `npm.cmd run build:win`：Windows x64 NSIS 安装包、blockmap 和 `latest.yml` 构建成功。
- Win32 `GetMonitorInfoW` 已在开发机直接验证，可返回 `\\.\DISPLAY1`、主屏标志和物理矩形。
- 本机静默覆盖安装成功：EXE、`app.asar` 和卸载注册表均为 1.1.11；原壁纸、8 个桌面组件和 2 个全局图标组件完整保留，8 个组件已迁移到稳定显示器键。
- 安装态诊断确认主屏以 `2560x1440` DIP、`3840x2160` 物理像素贴合成功，使用 Win11 Raised Desktop 原生路径。
- 当前开发机只有单显示器；混合 DPI 双显示器仍需在公司电脑完成最终实机验收。

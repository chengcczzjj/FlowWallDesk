# LingyueDesk 1.1.5 发布说明

> 发布日期：2026-08-24  
> 版本主题：便利贴字号与被动组件层级修复

## 核心更新

- 便利贴正文默认字号调整为 12px，并根据纸张宽高自动压缩，避免输入后文字过大。
- 便利贴保留字体、字号、粗体、斜体、下划线、删除线、列表和图片排版工具。
- 时间、天气、文字、行情、新闻、日历、音频可视化等只读组件不再参与 Canvas 鼠标命中和临时置顶修复。
- 修复窗口切换或全屏应用返回时，时间组件短暂闪到最前端的问题；编辑模式下仍可统一调整组件。
- 完成多显示器壁纸布局、跨屏延展和便利贴富文本链路的整合。

## 验证结果

- `npm.cmd test`：类型检查、lint 和 50 项单元/契约测试全部通过。
- `npm.cmd run build:win`：Windows x64 NSIS 安装包、blockmap 和 `latest.yml` 构建成功。
- GitHub Release `v1.1.5`：已上传自动更新资产，客户端可通过设置页检查更新或按启动轮询发现新版本。

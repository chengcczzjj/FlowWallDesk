# LingyueDesk 1.1.4 发布说明

> 发布日期：2026-08-23  
> 版本主题：全屏返回便利贴交互修复

## 核心更新

- 修复运行全屏 League of Legends 等游戏后，桌面便利贴仍可见但无法点击、输入或拖动的问题。
- 全屏窗口退出后，对所有桌面组件检查透明 Canvas 的原生命中表面，不再只依赖 Renderer 的 `elementFromPoint` 状态。
- 将壁纸窗口和桌面 Shell 识别为安全恢复表面；检测到 Canvas HWND 没有恢复到桌面层时自动重建 z-order 和鼠标命中状态。
- 保留 Dock 原有的原生点击兜底，并让便利贴与其他桌面组件共享同一套交互自愈流程。

## 验证结果

- `npm.cmd test`：类型检查、lint 和 43 项单元/契约测试全部通过。
- `npm.cmd run build:win`：Windows x64 NSIS 安装包、blockmap 和 `latest.yml` 构建成功。
- GitHub Release `v1.1.4`：已上传自动更新资产，客户端可通过设置页检查更新或按启动轮询发现新版本。

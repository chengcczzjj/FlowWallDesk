# LingyueDesk 1.1.3 发布说明

> 发布日期：2026-08-23  
> 版本主题：双显示器选择器与启动稳定性

## 核心更新

- 修复壁纸页右上角显示器按钮没有任何行为的问题。
- 显示器按钮现在弹出“全部显示器 / 主显示器 / 其他显示器”的目标选择菜单。
- 选择单台显示器后，再应用壁纸会自动切换到按显示器独立设置模式，并将壁纸写入对应显示器分配。
- 保留“打开显示器布局设置”入口，用于调整复制、跨屏延展和按屏壁纸分配。
- 增加显示器拓扑读取保护，启动和显示器热插拔期间 screen API 短暂不可用时不再让界面抛出未处理异常。
- 壁纸应用和显示器分配增加错误提示，避免 IPC 失败后界面状态假成功。

## 验证结果

- `npm.cmd test`：类型检查、lint 和 43 项单元/契约测试全部通过。
- `npm.cmd run build:win`：Windows x64 NSIS 安装包、blockmap 和 `latest.yml` 构建成功。
- 本地安装器使用未签名内部验证模式，并已更新本机客户端。

# LingyueDesk 1.1.9 发布说明

> 发布日期：2026-08-30  
> 版本主题：便利贴即时置顶与桌面画布性能优化

## 核心更新

- 便利贴在鼠标按下捕获阶段立即切换到最上层，不再等待鼠标抬起；拖动、缩放、文字编辑和设置操作均保持一致。
- 使用显式 `stackOrder` 持久化组件层级，便利贴重叠时按真实视觉顺序命中，切换壁纸或重启后层级仍能恢复。
- 新增独立 `widget:bring-to-front` IPC，置顶只更新层级，不会覆盖并发到达的位置或组件配置。
- Canvas 对未变化组件使用 `React.memo`，减少便利贴置顶时的无关渲染。
- 原生鼠标命中轮询改为自适应调度：交互期间 25ms，桌面空闲时 80ms，降低后台 CPU 唤醒。
- 保留 1.1.8 的 ToDesk 前台保护、全屏拖动、锁屏后 Canvas 重建和输入自愈逻辑。

## 验证结果

- `npm.cmd test`：类型检查、lint 和 54 项单元/契约测试全部通过。
- `npm.cmd run build:win`：Windows x64 NSIS 安装包、blockmap 和 `latest.yml` 构建成功。
- 本机安装态：EXE、`app.asar` 和卸载注册表均为 1.1.9；用户组件、全局图标组件和壁纸配置保持不变。

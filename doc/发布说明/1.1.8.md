# LingyueDesk 1.1.8 发布说明

> 发布日期：2026-08-30  
> 版本主题：ToDesk 远程控制前台闪烁修复

## 核心更新

- 修复 ToDesk 远程控制或覆盖层激活时，所有桌面组件与 Dock 短暂跳到远程窗口前台的问题。
- Canvas 仅在确认 Windows 桌面 Shell（Progman、WorkerW、任务栏、DefView）或无前台窗口时执行 z-order 恢复；普通应用前台状态不再强制 `alwaysOnTop`。
- 保留 1.1.7 针对开机长时间锁屏后的 Canvas 输入窗口重建和原生点击丢失自愈逻辑。
- 增加 ToDesk `H-SMILE-FRAME`、`TWINCONTROL` 类名回归保护和诊断日志 `canvas.desktop-return-recovery-skipped`。

## 验证结果

- `npm.cmd test`：类型检查、lint 和 52 项单元/契约测试全部通过。
- `npm.cmd run build:win`：Windows x64 NSIS 安装包、blockmap 和 `latest.yml` 构建成功。
- 本机安装态：EXE、`app.asar` 和卸载注册表均为 1.1.8；8 个组件、2 个全局图标组件及当前壁纸配置完整保留，正式安装进程响应正常。

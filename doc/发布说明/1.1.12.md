# LingyueDesk 1.1.12 发布说明

> 构建与本机安装日期：2026-09-05；远端正式发布：2026-09-06
> 版本主题：壁纸、组件与显示管理安全稳定补丁

## 核心更新

- 移除壁纸页三行显示模式说明，将模式与逐屏目标收进现有顶部导航同一行；本地/在线壁纸共用选择状态。菜单统一为圆角、浅色背景、蓝色悬停/选中样式，详情仅在悬停提示中显示。

- 组件配置读取不再回写空值或截断旧大记录；按壁纸命名空间原子保存，切换和退出前排空待写数据，损坏或写入失败时保留现场。
- Dock / 图标收纳在移动文件前保存恢复记录；导入与移除串行执行，部分恢复失败保留剩余记录，降低托管文件丢失风险。
- HTML 导入只复制选中的文件，不再顺带复制整个父目录；需要配套资源的网页请使用 ZIP，缺少 HTML 入口的包会被拒绝。
- 网页壁纸使用独立来源、资源真实路径边界、CSP 与 iframe 沙箱，阻止父页面、Node、bridge、跨包和越界文件访问。
- 壁纸模式、主显示器及组件命名空间统一协调；当前、次屏、断开显示器分配及进行中的应用均受资源删除/替换保护。
- 壁纸设置按 ID 合并、合并排队滑条写入，零音量可保存；复制/延展视频使用共同时钟且仅主屏出声。
- 工作区缩小时只临时调整组件显示位置、不破坏保存坐标；天气增加定时刷新、重试和过期提示，移除伪初值。
- 修复迟到的旧主屏快照覆盖设置，以及将已经加载的图片/网页壁纸变透明的问题。

# LingyueDesk 1.1.10 发布说明

> 发布日期：2026-08-30  
> 版本主题：多显示器壁纸布局恢复版

## 核心更新

- 修复显示器布局读取、写入和壁纸 renderer 被硬编码为按屏设置的问题；仅主屏、复制、按屏独立和跨屏延展四种模式重新真正驱动原生壁纸窗口。
- 修复在复制或跨屏延展模式下应用新壁纸后，布局被静默切回按屏设置的问题；只有明确指定某台显示器时才切换到独立分配。
- 恢复“设置 → 显示器”完整页面，提供 Windows 拓扑、四种布局模式和逐屏壁纸分配。
- 壁纸库顶部常驻显示布局选择器；按屏设置模式下额外显示目标显示器选择器，本地和在线壁纸使用同一应用目标规则。
- 保留普通多屏“一台显示器一个原生窗口”、跨屏延展“一个虚拟桌面窗口”的架构，并继续对延展模式强制使用 `cover` 铺满联合矩形。
- 新增调用链契约测试，防止主进程、IPC 或 UI 再次绕过持久化显示模式。

## 验证结果

- `npm.cmd test`：类型检查、lint 和 57 项单元/契约测试全部通过。
- `npm.cmd run build:win`：Windows x64 NSIS 安装包、blockmap 和 `latest.yml` 构建成功。
- 回归覆盖负坐标副屏、混合缩放、独立窗口、逐屏分配、跨屏联合矩形、强制铺满以及应用壁纸后保留布局。
- 本机静默覆盖安装成功：EXE、`app.asar` 和卸载注册表均为 1.1.10，当前壁纸、8 个桌面组件和 2 个全局图标组件保持不变。

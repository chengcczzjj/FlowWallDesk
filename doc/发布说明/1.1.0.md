# LingyueDesk 1.1.0 发布说明

> 发布日期：2026-08-17  
> 版本主题：自由便笺与桌面交互升级

## 核心更新

- 新增“一张任务一张纸”的自由便笺：可在桌面直接输入、像素级拖动、自由缩放、任意重叠并同时放置多张。
- 便笺改用 Windows 系统字体与 Sticky Notes 式极简排版，桌面可直接切换五种纸色与工作、学习、生活、健康、其他五个分类。
- 完成任务后播放 540ms 横向纤维撕除动画，便笺离开桌面但保留历史数据。
- 主应用新增便笺任务工作台，承载快速创建、时间分组、桌面显隐、完成归档、恢复、周复盘与未完成任务汇总。
- AI 对话可跨全部便笺实例查看、新增、修改、完成、恢复、删除和生成周总结。

## 桌面稳定性

- 补齐退出全屏游戏后的 WorkerW、DefView owner、透明 Canvas 合成和鼠标穿透恢复链路。
- 主进程命中桌面组件、但 renderer 未在 140ms 内接管鼠标时，可在 Canvas/桌面 Shell 表面安全自愈，不会错误覆盖普通应用。
- 重叠便笺的原生命中遵循实际渲染层级，优先选中最上方的纸张。
- Dock 启动缩放与扩散叠影从点击瞬间的真实悬停尺寸开始，消除尺寸跳变。

## 数据兼容

- 旧版聚合任务板会自动展开为多张独立便笺。
- 已完成时间、截止时间、分类和历史状态继续保留，并参与周统计。
- 原有壁纸、Dock、图标收纳和其他桌面组件配置不需要手动迁移。

## 验证结果

- `npm.cmd test`：37 项类型、lint、共享契约、发布契约和便笺回归测试全部通过。
- `npm.cmd run build:win`：Windows x64 NSIS 安装包、blockmap 和 `latest.yml` 构建成功。
- 未使用计算机控制做 UI 验收；全屏故障根因与恢复链路依据实际诊断日志和代码契约验证。

# LingyueDesk 1.1.2 发布说明

> 发布日期：2026-08-19  
> 版本主题：双显示器壁纸与桌面组件

## 核心更新

- 新增四种显示器布局：仅主显示器、复制到每台显示器、每台显示器单独设置、跨屏延展。
- 新增“设置 → 显示器”页面，展示显示器分辨率、缩放、Windows 坐标，并支持按显示器分配壁纸。
- 壁纸与组件画布支持 Windows 虚拟桌面坐标，兼容副屏位于主屏左侧或上方的负坐标布局。
- 显示器热插拔、分辨率和缩放变化后自动重算窗口边界与渲染分区。
- 组件保存的坐标会随虚拟桌面原点迁移，避免新增或移除副屏后组件跳屏。
- 全屏遮挡判断改为按全部显示器覆盖处理，副屏全屏应用不会误暂停主屏内容。

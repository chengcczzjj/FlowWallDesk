# 桌面任务便笺组件设计

> 调研与实现日期：2026-08-16  
> 组件类型：`todo-board`  
> 产品定位：把便利贴的低门槛、桌面常驻感与任务管理的结构化能力合并成一个轻量组件。

## 1. 用户目标

用户不需要先打开完整任务管理应用，而是在桌面上直接完成四件事：

1. 三秒内记下一件要做的事。
2. 一眼看见今天、逾期和后续任务，并直接勾选完成。
3. 不手工整理也能获得工作、学习、生活、健康分类。
4. 每周回看做完了什么、哪天最有进展、还有哪些任务未收尾。

AI 对话是第二入口：用户可以自然地说“加一条”“把刚才那条改到明天”“完成某项”“删除某项”或“总结上周”，AI 必须操作同一份真实任务数据。

## 2. 同类产品调研

### 2.1 来源与证据

| 产品 | 已观察能力 | 对本组件的启发 |
| --- | --- | --- |
| TickTick Desktop Sticky Notes | 任务可直接作为桌面便笺打开；支持全局快捷创建、置顶、一键排列、单行折叠；任务详情与便笺互通 | 桌面便笺的核心不是富文本，而是快速召回、低摩擦操作和占用空间可控 |
| Notezilla | 桌面常驻、提醒、复选清单、标签、文件夹、纸张皮肤，以及把便笺附着到网页/程序 | “提醒 + 勾选 + 组织”是成熟桌面便笺的基础组合；视觉材质能增强长期使用意愿 |
| Sticky Tasks (Microsoft Store) | 强调即时新增、整段粘贴、勾选、行内编辑和浮在桌面；明确不做重型项目管理 | 产品应保持窄而深：优先保证记录与完成，不复制项目管理器的复杂层级 |

### 2.2 需求分层

**同类产品共同的必需能力**

- 桌面常驻、可移动、可调整尺寸。
- 快速新增、复选完成、行内编辑、删除。
- 到期或逾期提示。
- 颜色/材质等可辨识的视觉外观。
- 重启后保存任务、位置和尺寸。

**任务工具提供、普通便利贴缺少的能力**

- 截止时间、优先级、标签或分组。
- 已完成历史与统计。
- 任务排序、过滤和跨时间回看。

**灵月适合形成差异化的能力**

- 根据中文任务标题自动识别工作、学习、生活、健康，无需先选列表。
- 在同一张纸上提供“计划 / 周记”双视图，而不是跳转到另一个页面。
- AI 对话与桌面直接操作共用真实数据，不生成一张不可维护的静态清单。
- 与现有壁纸采样毛玻璃结合，保留纸张温度又能自然融入当前桌面。

### 2.3 范围取舍

首版不引入项目、子任务、协作、附件、云同步和复杂重复规则。原因是这些能力会把三秒记录流程变成表单，并与灵月“轻量桌面伴侣”的产品方向冲突。

后续若有真实使用需求，可按优先级增加：自然语言日期、整段列表粘贴、重复任务、系统级定时通知、跨壁纸共享任务数据。

## 3. 产品方案

### 3.1 信息架构

组件分为四层：

1. 顶部：标题、未完成数量、总体完成率和可直接拖动的纸胶带把手。
2. 视图：计划 / 周记切换，逾期时显示聚合提醒。
3. 主体：计划视图按已逾期、今天、接下来、以后、随手记自动分组；周记视图显示总结、指标、七日完成柱和完成清单。
4. 底部：新增输入、今天/明天截止切换、重要级别以及自动分类说明。

### 3.2 自动分类

分类结果为 `work / study / life / health / other`。识别采用本地确定性关键词，避免新增任务依赖网络或模型：

- 工作：会议、客户、项目、需求、版本、发布、周报、邮件等。
- 学习：阅读、课程、作业、考试、教程、单词等。
- 健康：跑步、运动、喝水、体检、吃药、训练等。
- 生活：买菜、购物、快递、家务、做饭、缴费、旅行等。
- 其他：未命中时的安全兜底。

AI 或未来的高级编辑入口可以显式指定分类；桌面快速新增默认自动识别。

### 3.3 提醒

- 组件内提醒：逾期任务置于首组，显示红色时间标签，顶部汇总逾期数量。
- 系统提醒：应用运行且通知权限已授权时，每条逾期任务每天最多通知一次，使用 `localStorage` 去重。
- 不在应用退出后伪装后台定时器；真正的系统级计划通知留给后续主进程调度器。

### 3.4 周记

每周从周一开始，支持查看本周和过去 52 周。统计包含：

- 当周完成任务数。
- 当周计划收尾率。
- 有完成记录的活跃天数。
- 七天每日完成量。
- 当周完成清单和未收尾任务。
- 一句确定性自然语言总结，如“这一周完成 5 项，周三最有进展，还有 2 项未收尾”。

完成时间写入任务历史；恢复任务会清除完成时间，从而保证周统计真实。

## 4. 视觉方案

视觉方向名为 **Paper Pulse / 纸上脉搏**。

- 材质：暖奶油纸张叠加壁纸采样毛玻璃，而非通用白色玻璃卡片。
- 标识：左侧珊瑚色“任务脊线”代表未完成事项的持续脉搏。
- 拖动：顶部半透明纸胶带既是造型亮点，也是非编辑模式下可直接拖动的把手。
- 字体：标题使用 `Segoe Print / YouYuan` 营造手写感，正文使用 `Aptos / Microsoft YaHei UI` 保持高密度可读性。
- 分类色：工作蓝、学习紫、生活琥珀、健康绿；只用于小标签，不把整张卡染成彩虹。
- 形态：非对称圆角、细纸纹、轻微旋转元素和手绘感进度印章，避免模板化玻璃面板。
- 响应式：组件使用 CSS container query；低于 370px 时收起次要文字，低于 400px 高度时压缩标题与选项区。

## 5. 交互规则

- 拖动：非编辑模式按住顶部纸胶带立即拖动；其他非交互区域仍保留画布统一的安全长按移动。
- 缩放：全局编辑模式提供八方向拖拽手柄，最小尺寸 320×320，默认 420×520。
- 新增：输入标题按 Enter 或“记下”；截止按钮在无截止、今天 21:00、明天 21:00 间循环；重要按钮切换优先级。
- 完成：点击方框；已完成项进入“最近完成”，再次点击可恢复。
- 编辑：双击标题或点击铅笔，Enter/失焦保存，Escape 取消。
- 删除：悬停任务后显示删除按钮。
- 周记：可以前后翻周；点击已完成任务可恢复。

## 6. 数据与持久化

任务保存在 `WidgetInstance.config.tasks`，随组件配置由主进程写入当前壁纸的 userData 覆盖层。数据上限为 120 项，组件配置仍受 IPC 的 512KB 总量限制。

关键字段：

```ts
interface TodoTask {
  id: string
  title: string
  done: boolean
  createdAt: number
  updatedAt: number
  completedAt?: number
  dueAt?: number
  category: 'work' | 'study' | 'life' | 'health' | 'other'
  priority: 'high' | 'normal' | 'low'
  remind: boolean
}
```

## 7. AI 对话协议

专用工具 `manage_todo_tasks` 支持：

- `list`
- `add`
- `update`
- `complete`
- `reopen`
- `delete`
- `clear-completed`
- `weekly-summary`

新增任务时如果桌面还没有 `todo-board`，工具自动创建。修改、完成和删除必须先查看任务并使用准确 `taskId`，禁止根据标题猜测 ID。

## 8. 验收标准

- [x] 小组件管理页存在独立“任务便笺”类别，可添加/移除并显示当前尺寸。
- [x] 默认添加到桌面后可直接新增、完成、恢复、编辑和删除任务。
- [x] 顶部纸胶带可直接拖动，编辑模式可八方向自由缩放，最小尺寸正确。
- [x] 任务按时间分组并按标题自动分类，重要与逾期状态清晰。
- [x] 周记可前后翻周，统计与完成历史一致。
- [x] 逾期任务有组件内聚合提示，并在授权时提供每日一次系统通知。
- [x] AI 可操作同一份真实任务数据并返回周总结。
- [x] typecheck、lint、单元测试与生产构建通过。
- [ ] 跨壁纸共享任务、应用关闭后的系统级提醒、云同步不在首版范围。
